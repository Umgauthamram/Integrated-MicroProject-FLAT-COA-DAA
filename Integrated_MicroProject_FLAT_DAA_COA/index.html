🔤 Formal Language Specification & Transition Table $\delta(q, \sigma)$

In Formal Languages and Automata Theory (Module 1), a DFA guarantees $O(N)$ linear-time deterministic lexical validation without backtracking. Below are the formal components:

Formal 5-Tuple Definition

  • Q (States): {q0, q1, q2, q3, q4, q_accept, q_reject}
  • Σ (Alphabet): {LOAD, STORE, ADD, SUB, JMP, R0–R7, Imm(0–255), ',', ';'}
  • q0 (Start State): Initial idle state ready for instruction opcode.
  • F (Accept States): {q_accept} reached strictly after the semicolon terminator.
  • q_reject (Dead State): Sink state for any syntactic violation.

16-bit Micro-Instruction Control Word

• Bit [15:13]: Opcode (3 bits) - LOAD(001), STORE(010), ADD(011), SUB(100), JMP(101)
• Bit [12:10]: Destination Register (3 bits) - R0(000) to R7(111)
• Bit [9:7]: Source Register (3 bits) - R0(000) to R7(111)
• Bit [6:0]: Immediate Offset / Address (7 bits)

2 COA Module: 5-Stage RISC CPU Pipeline Simulator with Hazard Detection

Simulates Fetch (IF), Decode (ID), Execute (EX), Memory (MEM), and Write-Back (WB) with RAW and Control Hazard resolution.

⏱️ 5-Stage Pipeline Architectural Principles & Formulations

Computer Organization and Architecture (Module 2) demonstrates how instruction-level parallelism overlaps hardware stages to approach an optimal CPI = 1.00.

1. Data Hazards (RAW)

Occurs when an instruction requires operand data generated by an earlier instruction still in the pipeline. Resolved via hardware forwarding paths (EX-to-EX, MEM-to-EX) or by inserting stall bubbles.

2. Load-Use Hazard

LOAD instructions produce valid data only after the MEM stage. An immediately following instruction dependent on this data cannot execute in EX without at least 1 stall cycle, even with forwarding.

3. Speedup & CPI Formulations

Speedup $S = \frac{n \cdot k}{k + n - 1 + \text{Stalls}}$
$CPI = \frac{\text{Total Cycles}}{n}$
$\text{Throughput} = \frac{n}{\text{Total Cycles}}$

🧭 Greedy Choice Property & Min-Heap Asymptotic Complexity

Design and Analysis of Algorithms (Modules 1 & 2) establishes the theoretical guarantees of Dijkstra's single-source shortest path algorithm on non-negative directed weighted graphs.

Min-Heap Complexity Proof

  • • Initializing distances array takes $O(V)$ time.
  • • Each vertex is inserted and extracted from the priority queue at most once: $V \times O(\log V) = O(V \log V)$.
  • • Each directed edge is relaxed at most once. Each relaxation decreases key in the heap: $E \times O(\log V) = O(E \log V)$.
  • • Total Time Complexity: $O((V + E) \log V)$.
  • • Space Complexity: $O(V + E)$ for adjacency list and distance structures.

Greedy Choice Property

At each iteration, extracting the vertex $u$ with the minimal tentative distance $dist[u]$ guarantees that $dist[u]$ is the true shortest path distance, provided edge weights are non-negative. Any alternative path to $u$ via unvisited vertices must pass through some vertex $w$ with $dist[w] \ge dist[u]$, meaning it cannot be shorter.
